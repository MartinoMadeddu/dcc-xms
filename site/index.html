A node-based 3D application written in Rust. Model, unwrap, import, animate and export, with every step a node you can go back and change.

Everything stays live

Nothing is baked. A mesh is a cube node followed by the operations that shaped it. A mocap clip is a file node followed by the trims, renames and retimes applied to it. Change any value upstream and everything after it follows.

USD, at production size

  • Packed primitives: a file comes in as one piece per mesh prim, passed along without copying
  • Pick, then edit: choose pieces by path pattern; the nodes that follow work on those and pass the rest through
  • Materials and textures in the viewport, straight from the .usdz
  • A full transform stack, units and up axis converted

Polygon modelling in a single node

  • Edit Poly keeps a whole modelling session in one node, modelled on the Edit Poly modifier of 3ds Max
  • Five selection levels, picked in the viewport or by rule
  • Twenty-seven operations: extrude, bevel, inset, chamfer, bridge, connect, slice, subdivide and more
  • Manipulators on Q, W, E, R, and soft selection

UV unwrapping and UDIMs

  • Least squares conformal maps, with charts cut by angle and packed
  • UDIM tiles: separate pieces spread over tiles by size, with neighbours kept together
  • An editor that draws a million edges, with islands you can move, turn and scale

Motion capture, from take to engine

  • Real frame rates and timecode, drop-frame included
  • Clip tools: mirror, smooth, in place, blend, loop, retarget, time warp, prune, floor
  • Batch: split characters, T-pose, proxy skin and write FBX over a whole folder
  • Name patterns, not typing: joints chosen by regular expression, with a picker

An interface that gets out of the way

  • Dock anything anywhere, lock it, save it as a file
  • Your navigation: Maya, Houdini, XSI, Blender, Max, Modo or Unreal
  • Display modes: wireframe, hidden line removal, shaded, textured
  • Three themes, each with a colour editor
